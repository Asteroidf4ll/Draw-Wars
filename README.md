# 🎨 Drawar —— 多人娱乐绘画平台

**Drawar** 是一个面向学生、绘画爱好者及线上聚会场景的多人实时绘画平台。在传统茶绘（多人实时协作画板）基础上，融入了**随机事件**、**速写挑战**、**聊天表情**等游戏化机制，让绘画过程兼具创作、竞技与社交娱乐属性。


## ✨ 功能特性

### 🎯 核心功能
- **多人实时同步**：基于 WebSocket，多人在同一房间内绘画，延迟 < 100ms
- **房间系统**：4 位房间码加入/创建，无需注册，开箱即用
- **基础绘画工具**：笔刷、橡皮擦、颜色选择（RGB/色轮双模式）、笔刷大小/透明度调节
- **专业图层系统**：增删图层、显示/隐藏、锁定、不透明度、7 种混合模式、拖拽排序、缩略图预览
- **快照持久化**：房间状态自动保存，重新进入可恢复画布内容

### 🎲 娱乐创新功能
- **随机事件系统**：定时触发趣味事件，改变绘画体验
  - 黑白模式、水平/垂直镜像、鼠标反转、随机颜色
  - 共享撤回/重做、共享工具栏、工具抢夺（抢笔刷/橡皮权限）
- **速写挑战**：房主选择题目（预设图片分类 + 自定义题目），所有成员限时创作，参考图可缩放拖拽，倒计时结束自动锁定
- **聊天与表情互动**：
  - 聊天面板（历史消息 + 弹幕式浮窗）
  - 表情轮盘（按 `V` 键显示，数字键 `1-8` 发送）
  - 表情浮动动画（鼠标位置浮现后淡出）

## 🚀 快速开始

### 环境要求
- Python 3.10 及以上
- 现代浏览器（Chrome / Edge 推荐）

### 安装与运行

1. **克隆仓库**
   ```bash
   git clone https://github.com/asteroidf4ll/Drawar.git
   cd Drawar
2. **安装依赖**
- pip install flask
- pip install flask-socketio
- pip install flask flask-socketio eventlet
3. **启动服务器**
python app.py
4.**访问应用**
- 本机访问：浏览器打开 http://localhost:5000
- 局域网其他设备：访问主机 IP + :5000（例如 http://192.168.1.100:5000）
5.**开始绘画**
- 输入 4 位房间号加入房间，多台设备可同时体验实时协作。
## 📖 使用说明
### 基础操作
- 绘画：鼠标左键拖动画布
- 切换工具：点击工具栏「笔刷」/「橡皮擦」，选择预设
- 调节参数：滑块调整笔刷大小、透明度
- 颜色：点击色块打开调色板（RGB/色轮模式），支持前景色/背景色切换
- 图层：点击右侧「图层」按钮打开抽屉，可增删、排序、锁定、调整不透明度等
### 娱乐玩法
- 随机事件：房间内自动触发（可在「事件」面板查看、禁用事件），无需手动开启
### 速写挑战：
- 房主点击悬浮窗「配置挑战」，选择题目类别和时长
- 开始挑战后，所有成员看到同一参考图（可缩放拖拽）和倒计时
- 时间结束后画板自动锁定，可展示交流
### 聊天表情：
- 点击聊天按钮打开侧边栏，发送文字消息
- 按下 V 键显示表情轮盘，按数字键 1-8 发送表情（在鼠标位置浮现）
### 保存与恢复
- 自动保存：房间状态每 60 秒自动保存，也可手动点击「导出快照」
- 恢复：重新进入房间时自动加载最近快照

## ❓ 常见问题
- Q: 其他设备无法连接？
- A: 检查防火墙是否允许 5000 端口，或关闭 Windows 防火墙；确保所有设备在同一局域网。

- Q: 画面不同步或延迟高？
- A: 确认网络稳定；重启服务器；减少同时在线人数。

- Q: 快照无法恢复画布？
- A: 检查 snapshots/ 文件夹是否有对应房间号的 .json 文件；若无，手动点击「导出快照」保存一次。

- Q: 撤回/重做功能偶尔不同步？
- A: 已知问题：在极端并发快速连续操作时可能状态不一致。建议谨慎使用或通过「随机事件」中的共享撤回机制体验。

- Q: 如何自定义速写挑战题目？
- A: 在聊天界面点击「管理题目」按钮，可添加自定义文字题目或上传参考图（base64）。预设图片请放入 static/image/分类名/ 文件夹下。
